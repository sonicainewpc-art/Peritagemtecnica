# PeritOne — Peritagem Técnica de Edifícios e Obras

MVP em Streamlit para publicação no GitHub e deploy no Streamlit Community Cloud.

## Conteúdo
- 7 serviços de peritagem técnica
- Edifícios existentes e obras em curso
- Área: Algarve + Évora, Beja, Moura e Sines
- Formulário de pedido
- Envio preparado por WhatsApp e email
- Páginas legais
- Identidade visual verde + laranja
- Imagens fornecidas pelo cliente

## Deploy
1. Crie um repositório no GitHub.
2. Envie todos os ficheiros desta pasta, mantendo a pasta `assets/` e `pages/`.
3. No Streamlit Community Cloud, selecione o repositório e o ficheiro `app.py`.
4. Faça o deploy.

## Nota sobre o formulário
O botão de email abre o cliente de email do utilizador com o pedido já preenchido.
O botão WhatsApp abre uma conversa com o número configurado.

O email não é apresentado como texto na página; é usado apenas na ação de contacto.
